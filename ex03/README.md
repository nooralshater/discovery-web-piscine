# Git and GitHub Workflow

## Why Git Makes Development Easier

Git makes development easier because it keeps track of changes made to a project.

### 1. Protecting the Code

Git keeps a history of the project, so previous versions can be recovered if something goes wrong.

### 2. Tracking Changes

Git records changes through commits. This makes it easier to see what was changed and when.

### 3. Team Collaboration

Git allows multiple developers to work on the same project and share their changes through GitHub.

## Git Workflow

A basic Git workflow is:

1. Edit files
2. Add changes using git add
3. Save changes using git commit
4. Upload changes using git push

## GitHub

GitHub is a platform for hosting Git repositories and collaborating with other developers.
